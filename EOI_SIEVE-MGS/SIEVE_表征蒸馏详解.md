# 什么是"表征蒸馏"

SIEVE-MGS 的方法内核。配套阅读：[`SIEVE_蒸馏流程与数据构成.md`](SIEVE_蒸馏流程与数据构成.md)（全流程与数据构成）。

---

## 1. 一句话

**不让学生模仿老师的答案，而是让学生模仿老师内部的那张"地图"**——即老师把不同输入摆放在表征空间里的相对位置。

---

## 2. 三种蒸馏的区别

| 类型 | 学生对齐什么 | 需要老师具备什么 | 代表工作 |
|---|---|---|---|
| **输出蒸馏**（最常见） | 老师的软概率，如 [0.7 病毒, 0.3 非病毒] | **一个分类头** | Hinton, Vinyals & Dean 2015 |
| **表征蒸馏**（本项目） | 老师的**中间层嵌入向量** | 只要有表征空间 | FitNets (Romero et al. 2015) 及其后续 |
| 关系蒸馏 | 样本**两两之间的距离/夹角** | 同上 | RKD、CRD |

---

## 3. 为什么这里**只能**用表征蒸馏

这是最容易被忽略、但最关键的一点：

> **ESM-2 根本没有"是不是病毒"这个输出。**
> 它是在 UniRef 上做掩码语言建模训练的，是一个自监督基础模型，**不是分类器**。

**没有 logits 可抄。** 所以常规的输出蒸馏在这里不是"我们不选"，而是**根本不存在**。

ESM-2 所拥有的，只是一个嵌入空间——在那个空间里，结构与功能相似的蛋白彼此靠近。

**结论**：当教师是一个自监督基础模型时，**表征蒸馏是唯一可用的蒸馏形式**。这不是风格选择，是约束。

---

## 4. 直觉：地图 vs 判决

| | 学生得到什么 | 能做什么 |
|---|---|---|
| **输出蒸馏** | 老师对每道题的**判决** | 答好见过的题 |
| **表征蒸馏** | 老师脑中的那张**地图** | **定位老师从没讲过的地方** |

有了地图，你能找到没被标注过的位置。这正是新颖病原体检测需要的能力。

---

## 5. 一个具体例子

设三条 read：

| | 来源 |
|---|---|
| **A** | 已知冠状病毒的刺突蛋白编码区 |
| **B** | **留出分支**（训练时完全不存在）某病毒的刺突样蛋白编码区 |
| **C** | 大肠杆菌某代谢酶编码区 |

**ESM-2 嵌入空间里的实际布局**：

```
          ESM-2 表征空间（示意）

     ┌─────────────────────────────┐
     │                             │
     │    ●A      ●B               │   ← 病毒表面糖蛋白"住"的这一带
     │      ＼    ／                │      （折叠特征相似 → 彼此靠近）
     │       ＼  ／                 │
     │                             │
     │                             │
     │                    ●C       │   ← 细菌代谢酶在另一片区域
     │                             │
     └─────────────────────────────┘
```

**注意 A 与 B 为什么靠得近**：不是因为它们分类学上相关（它们不相关），而是因为 **ESM-2 从 UniRef 学到的是蛋白结构与功能的规律**——衣壳、聚合酶、糖蛋白的折叠特征跨科保守。

现在看两种损失分别教了学生什么：

| 损失项 | 传达的信息 |
|---|---|
| 监督项 | "A 是已知病毒，B 是新颖病毒，C 不是病毒" —— 三个**孤立的判决** |
| 表征匹配项 | "A 和 B 要放得近，C 要放得远" —— 一段**结构信息** |

**于是上线遇到分支 D（训练时完全不存在）时**：学生若真学会了画这张地图，D 的刺突样蛋白也会落到 A、B 附近 → 判为"像病毒"，且远离所有已知病毒的具体位置 → **两个头同时高 → 保留**。

---

## 6. 为什么这能跨分支泛化（机制）

| 训练配置 | 学生可以怎么"偷懒" |
|---|---|
| **只有监督项** | "这些特定 reads 是新颖病毒" → **背下这些分支特有的 k-mer 模式**就能拿满分。换个分支立刻失效 |
| **加上表征匹配项** | "把这条 read 放到 ESM-2 会放的位置" → 而 ESM-2 的摆放由**蛋白结构与功能**决定，其保守性**远超核酸一致性** |

核心逻辑链：

```
核酸一致性  ──低于 80% ANI 就基本消失
蛋白一致性  ──同样条件下仍有 80–90%
ESM-2 的几何 ──由蛋白结构决定，因而在发散区间依然有效
      ↓
表征匹配项逼学生去学"扛得住发散"的特征
      ↓
跨分支泛化
```

## 7. 损失函数与实现细节

```
总损失 = BCE(两个分类头, 标签)  +  λ · (1 − cos(z_student, z_teacher))
                                    └──────── 这一项就是全部的"蒸馏" ────────┘
```

`λ = 0` 就退化成普通的小模型训练。**λ 是这个项目的赌注。**

实现上要注意的几点：

| 事项 | 做法 | 原因 |
|---|---|---|
| 教师参数 | **完全冻结**，梯度不回传 | 教师是固定参照系，不是被训练对象 |
| 教师嵌入维度 | ESM-2 650M 输出 1280 维 → 降到 256 维 | 降维矩阵**只拟合一次**并固定，否则参照系会漂 |
| 归一化 | 两侧都做 L2 归一化后再算余弦 | 只对齐**方向**，不对齐模长 |
| 6 框汇合 | max-pool 或 attention-pool | 六个框里通常只有一个是真 ORF，均值会被噪声稀释 |
| λ 调度 | 前几个 epoch 从 0 warm-up | 一开始学生表征是随机的，硬拉会干扰监督项收敛 |
| 学生投影头 | **上线时丢弃** | 它只服务于这一项损失，推理不需要 |

## 8. 为什么不先把 ESM-2 微调成分类器，再做常规输出蒸馏？

这是评审很可能问的。三层理由，一层比一层重要：

**（1）信息量差两个数量级。**
分类头把 256 维的丰富几何压成 2 个数字。你等于把绝大部分可迁移的信息在中途扔掉了。

**（2）会把误差焊死。**
微调出的分类器自身的错误，会原封不动地传给学生，而且学生再也无法超越它。

**（3）最要命的：它自带我们想逃离的偏见。**
微调是在**已有分支**上做的，它的 logits 因此携带同样的分支偏好——**而整个项目的目的恰恰是泛化到那些分支之外**。用一个带偏见的老师去教"如何不带偏见"，逻辑上就不成立。

---

## 9. 值得一试的变体：关系蒸馏

师生的表征空间**绝对坐标未必可对齐**（两个模型的"坐标系"本来就不同）。因此匹配**相对结构**往往比匹配绝对位置更稳：

```
绝对匹配（当前方案）： z_student(i)  ≈  z_teacher(i)
关系匹配（备选）：     d(z_s(i), z_s(j))  ≈  d(z_t(i), z_t(j))     对所有样本对
```

关系匹配只要求"谁离谁近"的**格局**一致，不要求坐标一致——这与第 4 节"画同一张地图"的直觉其实更贴切。

**建议**：作为实现阶段的备选方案纳入消融，与绝对匹配一并比较。

---

## 10. 诚实地说：这是假设，不是定理

> **"对齐表征几何 → 跨分支泛化"在直觉上很有说服力，但没有被证明。**

这就是第 3 个月那个消融存在的全部理由：

| | A 组 | B 组 |
|---|:---:|:---:|
| 结构与参数量 | 完全相同 | 完全相同 |
| 监督项 | ✅ | ✅ |
| **表征匹配项** | ❌ λ=0 | ✅ λ>0 |

在**留出分支**上按 ANI 分层比较 AUPRC：

- **B 组在低 ANI（<80%）区间显著优于 A 组** → 主张成立，项目继续
- **两组无显著差别** → **本项目的前提是错的**。第 3 个月就知道，退路是放大学生模型（仍比教师快两个数量级），而这个否定结果本身也值得发表

---

## 11. 一页速查

| 问题 | 答案 |
|---|---|
| 蒸馏的是什么？ | ESM-2 的**中间层嵌入**，不是它的预测 |
| 为什么不蒸馏输出？ | **ESM-2 没有分类输出**，它是自监督语言模型 |
| 学生看得见蛋白吗？ | **看不见**。学生只吃原始核酸，学的是"落到 ESM-2 会放的位置" |
| 教师上线时跑吗？ | **不跑**。教师只在训练前离线跑一次，嵌入存盘 |
| 标签谁给的？ | **构造给的**（留出分支 + 模拟），不是教师给的 |
| 这套方法被证明了吗？ | **没有**。第 3 月消融就是为了检验它 |
| 失败了怎么办？ | 放大学生模型（仍比教师快两个数量级），并把否定结果发表 |
