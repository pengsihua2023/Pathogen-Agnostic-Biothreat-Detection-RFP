# SIEVE-MGS：蒸馏模型的流程与数据构成

写给项目内部理解与答辩准备用。对应 EOI 的 Aim 1。

---

## 0. 一句话和一个类比

**一句话**：请一位跑得很慢但很准的"专家模型"，离线把一批训练用的 reads 逐条看过；再训练一个极小的"学生模型"去模仿它，**不只模仿答案，还要模仿它的判断依据**；之后专家退场，学生以每秒五十万条的速度上线。

**类比**：

| 角色 | 对应 | 特点 |
|---|---|---|
| 世界级专家 | 教师模型（ESM-2 等） | 判断准，但看一条要几毫秒 → 每天百亿条根本看不完 |
| 实习生 | 学生模型（≤5M 参数 CNN） | 每条几微秒，但自己学容易死记硬背 |
| 培训方式 | **表征蒸馏** | 不只对答案，还要求"心里怎么想"和专家对齐 |

**为什么"模仿判断依据"是关键**：如果只让实习生背答案，他学到的是"我见过的这些病毒长什么样"；遇到从没见过的分支就废了。而让他对齐专家的**表征几何**，学到的是"病毒性"这个抽象结构——这正是新颖病原体检测需要的泛化能力。

> 这也是本项目**唯一可被证伪的核心主张**，第 3 个月的消融实验直接检验它（见第 6 节）。

## 2. 数据是怎么造出来的（本文重点）

### 2.1 三类样本，三种标签

训练集里每一条 read 都带两个标签：

| 来源 | y_viral | y_novel | 说明 |
|---|:---:|:---:|---|
| **真实污水背景 reads** | 0 | 0 | 细菌、宿主、未知非病毒物质。**用真实数据，不模拟** |
| **保留分支的病毒基因组** | 1 | 0 | 库里有的已知病毒 |
| **留出分支的病毒基因组** | 1 | **1** | 模拟出的"新颖病原体"，这是我们要抓的 |

上线时只保留 **两个头都高** 的 reads：既像病毒，又不像库里任何已知病毒。

### 2.2 关键设计：整个分支留出（leave-one-clade-out）

这是"真值从构造中来"的核心，也是整个数据设计里最容易被评审追问的一步。

做法是：**把某个分支从所有地方整体删掉**——

- 参考数据库（对照工具用的）
- 学生模型的训练集
- **教师模型的参考集**（这一条最容易漏，漏了就是信息泄漏）

然后从这个被删掉的分支的基因组里模拟 reads，作为"新颖"正样本。

> **为什么必须整个分支删**：如果只删掉某一株病毒、却保留它的近亲，模型只要认出近亲就能答对——这不是检测新颖病原体，是检测"我认识它表哥"。整个分支删掉，模型才真正面对"从没见过这一类"的情形。

### 2.3 难度用连续量标定，不用二元标签

每一条模拟 read 都记录一个难度指标：**到最近保留邻居的 ANI**（平均核苷酸一致性）。

- ANI 95% → 很像已知病毒，好抓
- ANI 70% → 高度发散，难抓
- **真正的新颖病原体通常落在 80% 以下**

所有结果**按难度分层报告**，不做汇总平均。因为汇总会被"简单样本"拉高，掩盖 80% 以下那个真正要命的区间。

### 2.4 模拟与混合的参数

| 项 | 取值 | 理由 |
|---|---|---|
| read 长度 | 75–300 bp | 覆盖主流 Illumina 配置 |
| 错误谱 | 平台真实错误模型 | 模拟得太干净，模型上线就崩 |
| 注入丰度 | 10⁻⁴ ~ 10⁻⁸ | 10⁻⁷ 是早期预警真正所在的区间 |
| 背景 | **真实污水 reads** | 真实噪声无法模拟：批次、降雨、稀释、宿主组成 |
| 双链 | 两条链都要 | 所以学生模型做成反向互补等变 |

### 2.5 一个必须说清楚的标签噪声

**真实污水背景里本来就含有病毒，其中一部分是未知病毒。** 我们把背景标成 `y_viral=0`，所以这部分是**标签噪声**，会让模型的"假阳性"被高估。

处理方式：
1. 背景 reads 先与已知病毒库比对，命中的重新标注
2. 剩余的未知病毒 reads 无法清除——**在论文和提案里如实说明**，并把它作为假阳性率的解释项

> 这是评审很可能会问的一点，提前想好比临场解释好。

## 3. 教师模型：为什么是这两个，为什么不是 Evo 2

### 3.1 教师是一个组合，不是单个模型

| 通道 | 模型 | 输入 | 抓什么 |
|---|---|---|---|
| **蛋白通道** | ESM-2 | read 的 6 框翻译 | 核酸层面同源性已被抹除，但衣壳/聚合酶/糖蛋白的折叠特征还在 |
| **核酸通道** | DNABERT-2 / ViraLM / Nucleotide Transformer | read 原始序列 | 核酸层面的组成与模式特征 |

两个通道的失效模式不重叠：核酸变异到认不出时，蛋白通道还在；蛋白编码区之外的片段，核酸通道还在。

### 3.2 为什么不用 Evo 2

**Evo 2 出于生物安全考虑，训练时刻意剔除了感染真核宿主的病毒序列**，因此它在真核病毒序列上困惑度很高——而那正是我们要找的东西。

> 最显眼的候选恰恰是错的。这一点写进 EOI 正文，是显示我们真懂这个领域的地方。

### 3.3 教师只跑一次

对训练集里每条 read：

```
read → 6框翻译 → ESM-2 → 嵌入向量   ┐
                                    ├─► 拼接/降维 → z_teacher（存盘）
read → 原始序列 → 核酸模型 → 嵌入向量┘
```

**存下来就完事了。** 之后训练学生时反复读这些向量，不再跑教师。上线更是完全不涉及教师。

## 4. 学生模型

| 项 | 设定 | 为什么 |
|---|---|---|
| 结构 | 反向互补等变的膨胀卷积网络 | read 来自哪条链是随机的，模型对两条链必须给同样的分 |
| 参数量 | ≤ 5M | 大了就跑不到目标吞吐 |
| 量化 | INT8 | 推理再快 2–4 倍 |
| 输入 | one-hot 编码，4 × L | 不需要任何参考索引 |
| 输出 | 两个分类头 + 一个投影头 | 前者出分数，后者用于对齐教师表征 |
| 长读 | 重叠分块处理 | ONT/HiFi 也能用 |

## 5. 损失函数：两项，这是蒸馏的全部

```
总损失  =  监督项  +  λ × 表征匹配项
```

**监督项**：两个头对 (y_viral, y_novel) 的交叉熵。因为新颖样本极少，要做类别加权。
→ 教学生"答案是什么"

**表征匹配项**：学生投影头输出的 z_student 与教师存下的 z_teacher 之间的余弦距离。
→ 教学生"专家是怎么想的"

**λ 就是这个项目的赌注。** λ=0 就退化成普通的小模型训练；λ>0 才叫蒸馏。

## 6. 第 3 个月的消融：整个项目押在这一步

训练两个**结构完全相同、参数量完全相同**的学生：

| | A 组 | B 组 |
|---|---|---|
| 监督项 | ✅ | ✅ |
| 表征匹配项 | ❌（λ=0） | ✅（λ>0） |

在**留出分支**上按 ANI 分层比较 AUPRC。

- **B 组在低 ANI（<80%）区间明显好于 A 组** → 主张成立，项目继续
- **两组没差别** → **本项目的前提是错的**，第 3 个月就知道，退路是放大学生模型（仍比教师快两个数量级），而这个否定结果本身也值得发表

> EOI 里那句 "If it is not, the premise of this project is wrong and we will know early enough to act" 指的就是这个。

## 7. 上线：打分之后怎么定阈值

学生模型给每条 read 两个分数，但**分数本身不能直接用**——你得知道"卡在哪里"会漏掉多少真货。

**conformal risk control** 解决这个问题：

1. 留一份校准集（与部署数据可交换，**按站点分别校准**）
2. 对一系列候选阈值 λ，算出"真正的新颖 read 被丢掉的比例"
3. 选出**在置信度 1−δ 下，漏检率仍 ≤ ε** 的最激进阈值

最终交付的不是某一个工作点，而是一条 **(ε, 压缩比) 曲线**：

> 你告诉我能容忍多少漏检，我告诉你数据能压掉几个数量级。

**这个保证会在什么时候失效**，我们也照实报告：conformal 依赖可交换性，而不同集水区、季节、文库化学之间并不可交换。所以做逐站点滚动校准，并专门测跨站点/季节/平台漂移下这个界退化多少。

## 8. 算力与数据量（具体数字）

| 环节 | 量级 | 成本 |
|---|---|---|
| 参考病毒基因组 | 10⁴–10⁵ | — |
| 留出分支折数 | 20–50 折 | — |
| 模拟新颖 reads | ~10⁷ 条 | CPU，小时级 |
| 真实背景 reads | 10⁷–10⁸ 条 | 已下载 |
| **教师嵌入（一次性）** | 10⁷ 条 × 6 框 = 6×10⁷ 条序列 | **约 5–20 GPU-小时**（ESM-2 650M；用 3B 模型则 ×10） |
| 学生训练 | 多轮 | 数十 GPU-小时 |
| **上线推理** | 10⁹ reads/天 | **约 1 GPU-小时/天**；纯 CPU 回退约 50 核心小时/天 |

> 预算里那条 **$30,000 GPU** 主要就是给"教师嵌入 + 学生训练 + 跨硬件吞吐基准"三项的。上线本身很便宜——**这正是整个项目的卖点**。

## 9. 最容易被误解的五点

| 误解 | 实情 |
|---|---|
| "上线时要跑大模型，太慢" | ❌ 教师只在训练前跑一次，上线只有 5M 参数的学生 |
| "蒸馏就是把大模型压小" | ❌ 常规蒸馏是对齐**输出**；这里对齐的是**表征**，目的是跨分支泛化而不只是压缩 |
| "标签从哪来？靠教师打标？" | ❌ 标签来自**构造**（留出分支 + 模拟），是精确真值。教师只提供表征，不提供标签 |
| "SIEVE 是个检测器" | ❌ 它是**前置滤网**。它界定的是**被丢掉的部分**，不承诺低假阳性——控假阳性是下游的事 |
| "组装一下再判断不是更准？" | ❌ 组装在 10⁻⁷ 丰度直接失效（几条 reads 拼不出 contig），而那正是早期预警所在的区间 |
